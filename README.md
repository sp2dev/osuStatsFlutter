# osu! stats checker

查看你的 osu! 统计数据！使用 Flutter 编写。（目前仅适配安卓端）

你的用户 token 存储在本地，不会上传至任何地方。

注意：**本项目完全由 AI 编写**

## 功能截图

![preview.webp](https://imgbed.theinspired.top/file/1777287158623_preview.webp)

## 功能列表

* 分模式查询
* 统计数据查询
* 查询其他用户
* 持久化保存 `CLIENT_ID` `CLIENT_SECRET` 和 查询用户名
