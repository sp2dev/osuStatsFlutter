# osu! stats checker

查看你的 osu! 统计数据！使用 Flutter 编写。

你的用户 token 存储在本地，不会上传至任何地方。

## 使用前必读

项目当前处于测试开发阶段（且用到了很多 AI 代码），随时可能有破坏性变更（包括数据库更改，存储结构更改等操作），请暂时不要长期使用。

如果有问题/建议，请发起 Issue。

## 功能列表

* 分模式查询
* 统计数据查询
* 查询其他用户
* 持久化保存 `CLIENT_ID` `CLIENT_SECRET` 和 查询用户名
